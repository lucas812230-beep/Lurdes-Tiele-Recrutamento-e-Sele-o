# Lurdes Tiele — Recrutamento e Seleção

Site institucional em HTML, com apresentação dos serviços para empresas e profissionais, pacotes de recrutamento e contato por WhatsApp.

## Como ver o site

Abra o arquivo `index.html` no navegador.

## Publicação

O site é um único arquivo estático e pode ser publicado com o GitHub Pages (Settings → Pages → branch `main`, pasta `/ (root)`).
